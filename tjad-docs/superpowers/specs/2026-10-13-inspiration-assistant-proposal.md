## 一、背景

### 1.1 行业背景

建筑设计行业正处于从增量扩张向存量深耕转型的关键期。城市更新、地域文化复兴、城市特色塑造成为项目主流方向，业主对设计方案的"在地性"要求显著提高——方案不仅要功能合理，更要回应目标场地的历史文脉、地域风貌与当代生活。这对设计院的前期策划与方案构思能力提出了全新要求：**谁能在最短时间内调动项目经验与地域知识，谁就能在前期竞争中占据先机**。

与此同时，人工智能技术特别是大语言模型与检索增强生成（RAG）技术快速成熟，为设计院的知识管理与能力复用提供了新的技术路径。头部设计企业已开始探索 AI 辅助设计，但普遍面临两个困境：通用大模型缺乏企业独家知识（项目经验、内部规范），检索精度与可信度不足；而传统知识管理系统只存不用，无法将沉淀的知识转化为生产力。

### 1.2 企业背景

我院在长期设计实践中积累了大量优秀设计项目、技术规范与工程经验，并通过内部业务系统（EKP）实现了文档的电子化归档。同时，我院已建成基于 WeKnora 的企业知识库平台与"百事通"智能问答前端，具备了知识入库、向量检索、智能问答的基础能力，并已实现内部规范、图档、维基等文档的持续自动化入库。

然而，现有知识资产以**事务性内容**为主（解决内部管理事务），面向**设计创作**的知识（优秀项目的设计要点、项目所在地的地域文化档案）尚未结构化沉淀；前端以通用问答为主，尚未形成面向具体设计场景的应用。知识"存而未用"、技术与主业"连而未通"，正是本课题要解决的问题。

### 1.3 契机

我院智能化客户端"百事通"已确立"能力即服务、知识即服务"的产品架构方向：智能体运行时保持通用，场景应用通过"人设 × 能力 × 知识"的组合配置快速生成。这意味着本课题不再需要从零开发应用，而是**在成熟底座上完成首个场景化应用与配套知识资产的共建**——技术条件、数据条件、平台条件均已具备，正是立项的最佳时机。

## 二、局限性分析（仅以"项目资料库"申报的不足）

若本课题仅以"项目资料库"为申报与交付内容，存在以下三重局限：

### 2.1 成果形态局限：数据库无法直接赋能集团主业

资料库是"被动资产"——数据躺在库里，需要用户主动检索、自行判断、人工整合才能产生价值。它与设计师的实际工作流（接任务书 → 找参考 → 挖文脉 → 出构思）之间存在断层，赋能链条最后一步靠人力完成，"赋能主业"难以量化证明。

### 2.2 定位局限：技术驱动而非场景驱动

"建数据库"是典型的技术驱动叙事：先有数据，再找用途。这导致课题验收只能以数据规模论英雄（入库多少条），而无法回答评审最关心的问题——**它解决了设计生产中的什么问题？**定位不高，创新性论证薄弱。

### 2.3 应用局限：缺少用户触点，价值闭环断裂

资料库没有交互前端，用户触点缺失，使用数据无从谈起；没有使用就没有反馈，没有反馈就无法迭代优化数据质量——数据资产的建设本身也失去了质量改进的闭环。

### 2.4 升维路径

本课题的解法是**将资料库从"交付物"降为"支撑层"，将"场景应用 + 数据资产 + 可复制方法论"升为交付物**：

- 百事通作为用户交互前端，提供能力入口 → 解决触点与主业赋能问题；
- 资料库/技能库作为后台支撑，通过场景应用产生直接生产力 → 解决定位问题；
- "能力即服务"架构使场景可复制 → 解决创新性与推广价值问题。

## 三、技术现状

### 3.1 已具备的平台基础

| 组件 | 现状 | 与本课题的关系 |
|---|---|---|
| 百事通桌面端 | 基于 Cherry Studio 企业化定制，助手/人格机制、插件市场、对话 UI 均已上线 | 直接复用为零改动前端；灵感助手以官方助手形式分发 |
| gateway 服务网关 | Python 服务，已具备知识检索（kb_search）、WeKnora 代理、企业用户鉴权、插件市场分发、模型代理等模块 | 课题新增能力的宿主；三张注册表在此落地 |
| WeKnora 知识库 | 生产运行中，支持文档入库、分块、向量检索、混合检索 | 知识存储与检索引擎，不改造，新增两个知识库 |
| EKP 数据管道 | 生产运行中，持续自动化入库内部规范、图档、维基（已完成 1.1 万+ 文档） | 建档管道的数据源与工程范式参考 |
| 算力资源 | 两台 4090 GPU 服务，分别承担 LLM 推理与向量化 | 中期扩容多模态 embedding 的硬件基础 |

### 3.2 行业技术现状与差距

- **通用 AI 助手**（ChatGPT、文心等）：无企业独家项目知识，无地域文脉结构化数据，生成内容泛化不可信。
- **行业知识库产品**：以文档管理为主，检索原始文档，无面向设计场景的知识重组与生成能力。
- **学术界的文脉研究数字化**：多为单点研究（某地某要素），无面向设计实务的持续更新数据服务。

**本课题的差异化定位**：独家内部项目经验（外部不可获取）× 结构化地域文脉库（行业稀缺）× 伴随式场景应用（超越检索问答）三者叠加，在行业内具有明确独特性。

### 3.3 待补齐的技术环节

面向设计创作的知识结构化（项目档案化、地域档案化）；外部公开数据的合规采集与持续更新机制；多模态检索（文字找图）；与生图服务的集成。以上均为成熟技术的场景化集成，无不可控技术风险（详见第七节风险预案）。

## 四、解决方案

### 4.1 总体思路

**方法论主轴**：能力即服务、知识即服务。智能体运行时不写死任何场景，场景应用 = 人设 × 能力 × 知识的一份组合配置（preset）。本课题交付的灵感助手是首个官方组合，其背后沉淀的三层注册机制（能力注册、知识注册、场景组合）可复制出任意数量的其他场景应用——**这是本课题区别于"做一个应用"的方法论价值**。

### 4.2 灵感助手：伴随式设计伙伴

面向设计师前期工作流，以设计任务书为起点：

1. **要素解析**：解析任务书，生成结构化要素卡（功能类型、地点、规模、风格倾向、约束条件），用户确认；
2. **三路检索**（并行）：内部优秀项目库（相似项目）、地域文脉库（目标地历史/文化/文脉/特产/风貌）、外部补充检索（未建库地区实时采集）；
3. **灵感简报**：融合生成结构化简报，所有素材注明来源；
4. **伴随式深化**：对话式追问、收窄、换向，会话状态显式维护不漂移；
5. **成果沉淀与升格**：收敛后生成《项目构思文档》（内部版），成熟后一键升格《前期策划提案》（对外版）。

### 4.3 输出三级阶梯

按能力成熟度自然涌现，不写死功能档位：

| 级别 | 内容 | 阶段 |
|---|---|---|
| L1 检索原始结果 | 三路检索素材包，带引用未加工 | 一期 |
| L2 生成报告 | 灵感简报/构思文档，结构化有叙事线，素材全回链 | 一期 |
| L3 图文+效果图 | 附项目实景/风貌图集 + AI 生成意向效果图（严格标注区分） | 二三期 |

### 4.4 数据资产建设

**优秀项目库（内部独家）**：对 EKP 历年评优项目原始图档进行 LLM 半自动结构化建档（设计要点提炼、概念关键词、图集归类、获奖信息），高置信自动入库、低置信人工确认，目标规模 300–400 个项目档案。

**地域文脉库（外部采集）**：双层机制——重点地区（首批长三角核心，扩展至 20 个）白名单建库并季度自动更新；其他地区按项目需要实时采集生成轻档案，高频命中地区自动晋升白名单。外部数据遵循"引用优于拷贝"原则（结构化摘要 + 来源链接），仅采集公开内容，严守合规红线。

### 4.5 技术路线与阶段划分

- **一期（M1–M2，1–6 月）**：文本闭环——三张注册表落地、五项核心能力、灵感简报与构思文档、建档管道 MVP（50→200 项目档案）、首批 5 个白名单地区、试点组（5–10 名设计师）真实使用；
- **二期（M3，7–12 月）**：多模态升级——图文混合检索（文脉找图、相似风貌项目）、提案升格闭环、使用数据半年报表；
- **三期（M4，13–18/24 月）**：生图集成与全院发布——意向效果图生成、灵感助手全院发布、资产终盘与结题。

技术架构详情见附表（第七节）。

### 附表 C：数据模型

**项目档案**：basic（名称/类型/地点/规模/年代/状态）、design（设计要点/概念关键词/空间策略标签）、culture（地域文脉标签）、honor（获奖/发表）、media（图集）、source（EKP 溯源 ID）。

**地域档案**：geo（行政区划）、history（沿革时间线/文脉叙事）、culture（非遗/特产/民俗，带来源链接）、fabric（格局/街巷尺度/材料/色彩/风貌元素）、media（风貌图集）、meta（来源清单/更新时间/命中次数）。

### 附表 D：三张注册表

- `capabilities`：能力定义（endpoint、输入输出 Schema、依赖、模态、状态）
- `knowledge_sources`：知识库登记（WeKnora kb_id、可过滤元数据字段、访问级别、资产统计）
- `presets`：场景组合（人设 + 能力集合 + 知识集合 + 可见性 official/pilot/draft）

灵感助手即一份 preset；换 preset 即换场景，此为可复制性的机制保证。

### 附表 E：数据源矩阵与合规策略

| 类别 | 候选源 | 合规级别 |
|---|---|---|
| 官方公开 | 政府文旅/规划网站、地方志平台、文保名录 | 可全文采集（白名单地区） |
| 百科/学术 | 维基/百度百科、公开论文摘要 | 仅摘要+引用链接 |
| UGC/影像 | 马蜂窝、小红书公开页、公开图库 | 仅摘要+引用链接，影像注明版权 |

红线：不采集登录/付费墙内容；引用优于拷贝；季度重保更新；来源全程可溯。
